partenza per la homepage di release: si usano così come sono o si
ritoccano (busta nella feritoia, scritte, marchi, colore). Il tryout della
homepage aveva disegni segnaposto; queste foto danno il realismo che cerchiamo.

metadati, stanno in `components/home-landing/assets/`. Quando ritocchi una
foto, lascia qui l'originale e salva il ritocco come file nuovo.
